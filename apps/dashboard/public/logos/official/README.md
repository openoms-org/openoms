# Official Provider Logo Assets

This directory is reserved for provider logo assets copied from official or explicitly approved sources.

## Rules

- Add a logo here only when the provider has an official download page, brand kit, or partner approval.
- Keep the asset visually unmodified except for file naming or safe format optimization.
- Record the source URL and review date in `src/lib/provider-info.ts`.
- If usage is not clearly approved, use the generated wordmark fallback in `ProviderLogo` instead.
