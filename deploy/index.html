// FOR DEVELOPERS

Twój stack, Twoje zasady

Go + Next.js monorepo z czystą architekturą. Fork, extend, deploy na swojej infrastrukturze.

  • Go 1.24 + chi router + pgx/v5
  • Next.js 16 + React 19 + TypeScript
  • PostgreSQL RLS multi-tenancy
  • OpenAPI 3.1 + Swagger UI
  • Docker Compose / Helm chart
  • 21 standalone SDK pakietów (MIT)
// FOR SELLERS

Skup się na sprzedaży

82 gotowe strony dashboardu. Zamówienia, przesyłki, zwroty, faktury — wszystko w jednym miejscu.

  • Allegro + InPost — działają od startu
  • Auto-etykiety i śledzenie paczek
  • Automatyzacja zamówień (rules engine)
  • Zwroty i reklamacje (RMA)
  • Raporty, CSV export, wydruki
  • Kanban board + barcode scanning
FEATURES

Wszystko w jednym systemie

12 modułów, od zamówień po faktury. Każdy z pełnym API i UI.

Zamówienia

Statusy, tagi, custom fields, merge/split, bulk operacje, Kanban board.

Produkty

Warianty, bundling, kategorie, waga/wymiary, zdjęcia, import CSV.

Magazyny

Multi-warehouse, dokumenty PZ/WZ/MM, inwentaryzacja, strict inventory.

Zwroty (RMA)

6-statusowy lifecycle, self-service portal, auto-refund, print slip.

Automatyzacja

Rules engine: trigger + conditions + actions. Scheduled delays.

Przesyłki

8 przewoźników, auto-label, rate shopping, tracking, batch labels.

Marketplace

8 integracji: Allegro, Amazon, WooCommerce, eBay, Kaufland, OLX, Mirakl, Erli.

Faktury

Fakturownia, KSeF (e-faktury), print templates, multi-currency (NBP).

Raporty

Revenue charts, trends, advanced reports, Prometheus metrics.

Webhooks

Outgoing webhooks z HMAC-SHA256, delivery log, retry policy.

Multi-tenant

PostgreSQL RLS, izolacja danych, per-tenant settings, custom branding.

Security

RBAC, 2FA/TOTP, Ed25519 JWT, audit log, CSP headers, encryption at rest.
