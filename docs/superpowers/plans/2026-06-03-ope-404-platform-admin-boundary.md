# OPE-404 Platform-Admin Boundary Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Establish a platform-admin identity + permission + route-isolation boundary that is completely separate from tenant RBAC, as the foundation for the Provider Integration Studio (OPE-405+).

**Architecture:** A dedicated non-tenant-scoped `platform_admins` table grants granular `providers:*` permissions to specific users. New `RequirePlatformAdmin` / `RequirePlatformPermission` middleware (which do NOT reuse tenant `RequireRole`/`RequirePermission`) gate an isolated `/v1/platform/*` route group. A separate `platform_audit_log` table records platform-admin actions. Platform admins authenticate via the existing login (JWT → user_id); authorization is entirely separate.

**Tech Stack:** Go 1.25, chi/v5, pgx/v5, golang-migrate, Ed25519 JWT, testify.

---

## Scope

In scope (OPE-404 only):
- `platform_admins` + `platform_audit_log` tables (migration 000031), no RLS, role grants.
- `model.PlatformAdmin` + platform permission constants.
- `repository.PlatformAdminRepository` (GetByUserID, Create) + `repository.PlatformAuditRepository` (Log).
- `middleware.RequirePlatformAdmin` + `middleware.RequirePlatformPermission` + platform context helpers + `PlatformAdminLookup` interface.
- `handler.PlatformHandler.Me` (whoami) — the minimal endpoint proving the boundary.
- Router wiring: isolated `/v1/platform` sibling group (JWTAuth + RequirePlatformAdmin, NO TenantPlanGuard).
- Tests proving tenant owners/admins/members are rejected; platform admins lacking a specific permission are rejected.

Out of scope (later tasks): provider registry/versioning (OPE-405), schema contract (OPE-406), capability/mappings (OPE-407), validation engine (OPE-408), Studio UI (OPE-409-411), platform-admin management UI/CRUD endpoints.

## Key Decision

**Authentication reuses the existing login; only authorization is separate.** A platform admin is an existing user (JWT carries `user_id` in `claims.Subject`) whose `user_id` appears in `platform_admins`. This satisfies the spec requirement of separate *authorization* (separate table, permissions, middleware — no tenant role grants the `providers:*` permissions) without building a second authentication system. A fully separate platform login can be added later without reworking this boundary.

## Data Model (migration 000031)

```sql
-- platform_admins: NON-tenant-scoped. No RLS (platform identity transcends tenants).
CREATE TABLE public.platform_admins (
    id          uuid PRIMARY KEY DEFAULT public.uuid_generate_v4(),
    user_id     uuid NOT NULL UNIQUE REFERENCES public.users(id) ON DELETE CASCADE,
    permissions text[] NOT NULL DEFAULT '{}'::text[],
    created_at  timestamptz NOT NULL DEFAULT now(),
    updated_at  timestamptz NOT NULL DEFAULT now()
);
-- Deliberately NO "ENABLE/FORCE ROW LEVEL SECURITY": platform_admins is global,
-- read with the app pool outside any tenant context.

-- platform_audit_log: dedicated platform-admin audit stream, NON-tenant-scoped.
CREATE TABLE public.platform_audit_log (
    id            bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    actor_user_id uuid REFERENCES public.users(id) ON DELETE SET NULL,
    action        text NOT NULL,
    target_type   text,
    target_id     text,
    metadata      jsonb NOT NULL DEFAULT '{}'::jsonb,
    ip_address    inet,
    created_at    timestamptz NOT NULL DEFAULT now()
);
CREATE INDEX idx_platform_audit_action_created ON public.platform_audit_log (action, created_at DESC);
CREATE INDEX idx_platform_audit_actor ON public.platform_audit_log (actor_user_id, created_at DESC);
```

Role grants (mirror migration 000028 dynamic pattern — grant to `openoms` + `openoms_app` if those roles exist; the worker/superuser already has rights). Both tables must be readable+writable by the app role used for platform routes. Use a DO block checking `pg_roles` to `GRANT SELECT, INSERT, UPDATE, DELETE ON public.platform_admins, public.platform_audit_log TO <role>` and `GRANT USAGE, SELECT ON ALL SEQUENCES` for the identity sequence.

`.down.sql`: `DROP TABLE IF EXISTS public.platform_audit_log; DROP TABLE IF EXISTS public.platform_admins;`

```go
package model

import (
	"time"

	"github.com/google/uuid"
)

// Platform-admin permissions. Colon-style to visibly differ from tenant
// dot-style permissions (e.g. "orders.view"). No tenant role grants these.
const (
	PermPlatformProvidersRead     = "providers:read"
	PermPlatformProvidersWrite    = "providers:write"
	PermPlatformProvidersValidate = "providers:validate"
	PermPlatformProvidersPublish  = "providers:publish"
	PermPlatformProvidersSecrets  = "providers:secrets"
)

// PlatformAdmin is an OpenOMS operator with platform-level (cross-tenant)
// provider-administration powers. Identity is separate from tenant RBAC.
type PlatformAdmin struct {
	ID          uuid.UUID `json:"id"`
	UserID      uuid.UUID `json:"user_id"`
	Permissions []string  `json:"permissions"`
	CreatedAt   time.Time `json:"created_at"`
	UpdatedAt   time.Time `json:"updated_at"`
}

// HasPermission reports whether the admin holds the given platform permission.
func (a *PlatformAdmin) HasPermission(perm string) bool {
	for _, p := range a.Permissions {
		if p == perm {
			return true
		}
	}
	return false
}
```

```go
package middleware

import (
	"context"
	"encoding/json"
	"net/http"

	"github.com/google/uuid"
	"github.com/openoms-org/openoms/apps/api-server/internal/model"
)

// PlatformAdminKey is the context key for the resolved platform admin.
const PlatformAdminKey contextKey = "platform_admin"

// PlatformAdminLookup resolves a platform admin by user ID.
// Implemented by repository.PlatformAdminRepository. Returns a non-nil error
// (e.g. pgx.ErrNoRows) when the user is not a platform admin.
type PlatformAdminLookup interface {
	GetByUserID(ctx context.Context, userID uuid.UUID) (*model.PlatformAdmin, error)
}

// PlatformAdminFromContext returns the resolved platform admin, or nil.
func PlatformAdminFromContext(ctx context.Context) *model.PlatformAdmin {
	if a, ok := ctx.Value(PlatformAdminKey).(*model.PlatformAdmin); ok {
		return a
	}
	return nil
}

// RequirePlatformAdmin authenticates the request as a platform admin. It MUST
// run after JWTAuth (which sets UserIDKey). It deliberately does NOT consult
// tenant roles/permissions. Non-admins get 403; unauthenticated get 401.
func RequirePlatformAdmin(lookup PlatformAdminLookup) func(http.Handler) http.Handler {
	return func(next http.Handler) http.Handler {
		return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
			userID := UserIDFromContext(r.Context())
			if userID == uuid.Nil {
				writePlatformError(w, http.StatusUnauthorized, "authentication required")
				return
			}
			admin, err := lookup.GetByUserID(r.Context(), userID)
			if err != nil || admin == nil {
				writePlatformError(w, http.StatusForbidden, "platform administration access required")
				return
			}
			ctx := context.WithValue(r.Context(), PlatformAdminKey, admin)
			next.ServeHTTP(w, r.WithContext(ctx))
		})
	}
}

// RequirePlatformPermission requires a specific platform permission. It MUST
// run after RequirePlatformAdmin.
func RequirePlatformPermission(required string) func(http.Handler) http.Handler {
	return func(next http.Handler) http.Handler {
		return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
			admin := PlatformAdminFromContext(r.Context())
			if admin == nil {
				writePlatformError(w, http.StatusForbidden, "platform administration access required")
				return
			}
			if !admin.HasPermission(required) {
				writePlatformError(w, http.StatusForbidden, "insufficient platform permissions")
				return
			}
			next.ServeHTTP(w, r)
		})
	}
}

func writePlatformError(w http.ResponseWriter, status int, message string) {
	w.Header().Set("Content-Type", "application/json")
	w.WriteHeader(status)
	_ = json.NewEncoder(w).Encode(map[string]string{"error": message})
}
```

## Risks

- **Routing overlap:** `/v1/platform` mounted as a sibling of `/v1`. Mitigation: mirrors the existing `/v1/auth` + `/v1` coexistence; verified by build + a request to `/v1/platform/me`.
- **RLS omission is intentional:** platform tables have NO RLS by design; a reviewer must confirm this is deliberate and that no tenant query joins them.
- **FK to RLS table:** `platform_admins.user_id` → `users(id)` (RLS table). FK integrity checks bypass RLS, so this is fine; verified by migration apply + insert in integration env.
- **Privilege creep:** ensure `providers:*` permissions are never added to tenant role permission sets.

## Rollback Notes

`migrate down` drops both tables (no other table references them). The router group is gated by `deps.PlatformAdmin != nil`, so reverting the bootstrap wiring disables the surface without code removal.
